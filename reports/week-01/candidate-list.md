# Week 01 candidate list

Overview search completed on 2026-10-05. This list was added after the first detailed evaluations, rather than before them. Overview relevance is a screening judgement, not a completed feature evaluation.

| Candidate and source | Why relevant | Selection outcome |
| --- | --- | --- |
| [Portkey](https://portkey.ai/docs/product/ai-gateway) | Direct AI gateway alternative for provider access and policies. | Selected, ALT-01. |
| [Azure API Management](https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities) | Existing enterprise API platform with generative AI gateway capabilities. | Selected, ALT-02, adjacent enterprise platform. |
| [LiteLLM](https://docs.litellm.ai/docs/simple_proxy) | Self-hosted proxy and Python extension hooks. | Selected, ALT-03, open-source comparison. |
| [Kong AI Gateway](https://developer.konghq.com/ai-gateway/) | AI gateway built around an established API gateway and plugins. | Not selected for detailed evaluation this week; enterprise platform category already represented. |
| [Bifrost](https://github.com/maximhq/bifrost) | Gateway providing a unified API for multiple model providers. | Not selected this week; another candidate for testing the self-hosted gap hypotheses later. |
| [Higress](https://github.com/higress-group/higress) | API and AI gateway project with an extension ecosystem. | Not selected this week; self-hosted gateway category already represented. |
| [Helicone AI Gateway](https://github.com/Helicone/ai-gateway) | AI gateway project relevant to centralizing provider requests. | Not selected this week; retain for a later direct comparison if logging becomes the focus. |
| [Apache APISIX AI proxy](https://apisix.apache.org/docs/apisix/plugins/ai-proxy/) | AI forwarding plugin within an extensible API gateway. | Not selected this week; adjacent plugin platform category already represented. |
| [Tyk](https://github.com/TykTechnologies/tyk) | General API gateway, relevant to authentication and extensibility around provider APIs. | Not selected this week; adjacent alternative rather than a deeply evaluated LLM gateway. |
| [Envoy Gateway](https://github.com/envoyproxy/gateway) | General gateway project, relevant to deployment and routing infrastructure. | Not selected this week; adjacent infrastructure rather than a directly evaluated LLM product. |

The selected three cover a direct product, an adjacent enterprise platform, and a self-hosted option. The other seven were excluded from this week's detailed scope, not shown to be worse products. They remain candidates if our proposed gaps do not survive validation.
