# Sentence Cards Generator

Status: Week 1 research and initial repository setup.

## Project

Language learners need a less tedious way to create and update sentence flashcards with translations and pronunciations from texts they study.

The course project proposes generating sentence cards for words selected in uploaded texts, supporting Russian, English, and German, teacher review, and spaced repetition. Week 1 research and Customer feedback will establish the scope; these capabilities are not implemented yet.

Repository: [ITPD-Almo/sentence-cards-gen](https://github.com/ITPD-Almo/sentence-cards-gen).
