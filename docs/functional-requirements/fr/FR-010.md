# FR-010: Verify And Restore A Deployed Release

- **Status:** Active
- **Traces to:** [`US-06`](https://github.com/ITPD-Almo/modular-llm-gateway/issues/66), [`CON-04`](../../product-vision.md#con-04)
- **Containers:** `gateway`

## Behavior

After each deployment, the product shall run normal-order, changed-order, plugin-error and timeout-recovery smoke checks against the deployed endpoint and mark the deployment failed when any check fails.

When a deployment fails its checks, the product shall allow the operator to restore the previous known-good artifact and configuration by the documented procedure.

Implementation status: target behavior for an unscheduled candidate story that depends on [FR-009](FR-009.md); not yet fully refined.

## Acceptance Criteria

### AC-01

Given a deliberately broken deployment, when its smoke checks run, then at least one check fails and the deployment is not reported healthy.

### AC-02

Given a failed deployment, when the operator follows the restore procedure, then the endpoint reports the previous artifact's identifier and all smoke checks pass without a real provider key.
