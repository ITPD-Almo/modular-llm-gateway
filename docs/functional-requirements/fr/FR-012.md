# FR-012: Record Privacy-Safe Configured Chat Outcomes

- **Status:** Proposed
- **Traces to:** [`US-11`](https://github.com/ITPD-Almo/modular-llm-gateway/issues/110), [`VP-02`](../../research/value-proposition.md#vp-02)
- **Containers:** `gateway`
- **Addresses:** [`ADR-007`](../../architecture/adr/ADR-007.md)

## Behavior

When analytics export is explicitly enabled, the gateway may enqueue bounded, content-free events for a configured pipeline's first observed use, a chat start, and a chat finish. Events contain only the registry fields in [`docs/analytics.md`](../../analytics.md); no body, header, IP, username, free text, token, credential, exception text or request metadata is exported. The source is a trusted bounded environment value: `web`, `usability-test` or `smoke`.

Export is best effort and opt-in. A full queue or unavailable exporter does not change the normal HTTP result. The gateway observes first use after application start, not deployment or restart by itself.

## Acceptance Criteria

### AC-01

Given enabled analytics and a configured plugin pipeline, when the first real chat is processed, then exactly one configuration-use event and one start/finish pair are emitted with bounded fields and opaque random IDs.

### AC-02

Given a request containing synthetic secrets in bodies, headers or metadata, when analytics is captured, then no secret appears in an event or exporter payload.

### AC-03

Given analytics disabled, a full queue or an exporter outage, when a normal or failed chat is processed, then the gateway's HTTP behavior is unchanged and no export is required.

### AC-04

Given `source=smoke`, when events are queried, then smoke events can be excluded without excluding `web` or `usability-test` events.

### AC-05

Given no completed configured chat in a seven-day window, when the focus query is evaluated, then it returns `not meaningful` rather than zero adoption; a zero denominator for a rate returns `not meaningful`.

### AC-06

Given a configured chat with HTTP success and a visible plugin result, when the finish event is queried, then it contributes to the completed-chat numerator exactly once.

### AC-07

Given synthetic smoke traffic, when staging and production queries are compared, then staging smoke is visible in raw events but excluded from both metric queries and production has no test traffic.
