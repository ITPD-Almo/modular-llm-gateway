# FR-005: Show What Each Plugin Changed

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/ITPD-Almo/modular-llm-gateway/issues/42), [`DEC-005`](../../decisions.md#dec-005)
- **Containers:** `gateway`

## Behavior

The gateway shall return with every successful response the ordered list of changes that plugins recorded at the request stage, followed by the changes recorded at the response stage, each naming the plugin, the stage and the change.

Implementation status: already implemented in [v0.1.0](https://github.com/ITPD-Almo/modular-llm-gateway/releases/tag/v0.1.0).

## Acceptance Criteria

### AC-01

Given the default configuration, when the request from [FR-001 AC-01](FR-001.md#ac-01) is sent, then `plugin_changes` holds four entries in this order: `metadata` at `request`, `uppercase` at `request`, `metadata` at `response`, `uppercase` at `response`.

### AC-02

Given a configuration that adds a plugin that records no change, when the same request is sent, then no `plugin_changes` entry names that plugin and the other four entries are unchanged and in the same order.
