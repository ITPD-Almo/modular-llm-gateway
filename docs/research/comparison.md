## Reading the table as a whole

Based on ALT-01 and ALT-02 only; to be revisited once ALT-03 is in.

- **Custom policies force a trade-off (P1).** One product runs company logic out-of-process (webhook, latency, fail-open); the other runs it in-process but in a proprietary language that fails at run time. Neither offers in-process plugins written in a general-purpose language that can be tested before deployment.
- **Company-specific sensitive data is unsolved in both (P4).** ALT-01 has fixed PII patterns; ALT-02 has none. Both push company identifiers (project codes, employee numbers) to hand-written regex.
- **Governance follows the vendor's pricing or cloud (P2, P5, P6).** ALT-01 gates SSO, admin audit, and VPC hosting behind Enterprise; ALT-02 gates features by tier and ties hosting to Azure.
- **Routing is not a differentiator (P3).** Both already cover fallback, weighting, and conditions; building a better router is unlikely to be valued.

These are inputs to `gap-analysis.md`, not gaps yet: each still needs the four gap tests.
