## Reading the table as a whole

The provisional direction and rejection of generic plugins as an advantage are recorded in [DEC-002](../decisions.md#dec-002).
These are patterns in the comparison, not confirmed user needs. Candidate gaps and rejected directions are recorded in [gap-analysis.md](gap-analysis.md).

1. **Plugins already exist (P1).** ALT-01 has TypeScript plugins and ALT-03 has Python callbacks/custom guardrails; ALT-02 has C# policy expressions. Reject the claim that a general-purpose plugin gateway is missing. The useful question is whether our narrower workflow is easier to understand and verify for this Customer.
2. **Masking and body-free logging already exist (P4, P5).** ALT-01 supports custom regex redaction, ALT-02 allows regex/body transformation, and ALT-03 offers Presidio and a global logging control. Reject generic PII masking or body-free logging as unique advantages. None of this establishes reliable handling of every kind of confidential prose.
3. **Usage records and administrative audit are different (P2, P5).** ALT-01 and ALT-03 list ready-made admin audit under Enterprise. ALT-02 includes Azure Activity Log for resource changes. The narrower question is whether each policy decision can be linked to the exact policy version active for that request. We have not established that existing products cannot provide this correlation. See provisional GAP-01.
4. **Deployment depends on which features are enabled (P6).** ALT-01's SaaS is convenient but its documented enterprise data plane still has infrastructure; ALT-02 is tied to Azure; ALT-03 can start small, while keys, Presidio, and multi-instance operation add services. A single-instance bundle with static access rules may serve a smaller job, but only a matched deployment trial can establish lower effort. See provisional GAP-02.
5. **Routing is already well served (P3).** All three cover useful routing/failover mechanisms. Reject generic fallback or load balancing as a gap; this does not prove no user would value a more specific routing rule.
