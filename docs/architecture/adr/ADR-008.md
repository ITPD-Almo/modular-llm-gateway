# ADR-008: Export Request Outcomes To OpenObserve

- **Status:** Accepted
- **Created:** 2026-11-08
- **Updated:** 2026-11-08
- **Containers:** `gateway`
- **Addresses:** [FR-013](../../functional-requirements/fr/FR-013.md), [QR-08](../../quality-requirements/qr/QR-08.md), [QR-03](../../quality-requirements/qr/QR-03.md)

## Context

The system operator must find one failed chat by its response identifier and inspect latency for failures across a recent window. Existing hook events identify a failing hook, but do not provide a remotely queryable request-level observation or a latency distribution.

## Considered Options

- **Structured request point and histogram in the parent, exported over OTLP:** uses the same duration for correlation and aggregation, with a bounded number of series.
- **Histogram labelled by request ID:** creates an unbounded number of series.
- **Export worker output or persist request bodies:** transfers data the operator does not need for this investigation.

## Decision Outcome

Use the OpenTelemetry SDK to export a structured request log point and a delta histogram over OTLP/HTTP to OpenObserve. Partition staging and production by organization. Request IDs appear only in the log, with fixed outcome and route labels on both signals. An opt-in exporter keeps network delivery outside request handling and drops queued data under pressure. [SLI-01](../../observability.md#sli-01) owns the queries and timing.

[ADR-006](ADR-006.md) deferred persistent metrics and dashboards. This decision adds them for request diagnosis. ADR-006's process-local counters and reset behavior remain the planned design for US-07.

## Consequences

- **Analysability — [QR-08](../../quality-requirements/qr/QR-08.md):** the log query identifies the specific request; the aggregate shows the failure-series latency. A backend outage can interrupt this evidence without interrupting the chat path.
- **Confidentiality — [QR-03](../../quality-requirements/qr/QR-03.md):** typed fields and a fixed event body keep content, keys, addresses and exception text out of these observations. Organization-scoped access and retention are operator configuration.
- **Resource cost:** finite histogram dimensions and a bounded log queue limit application state. The external backend owns data retention and its dashboards.
