# QR-09: Complete the main gateway task unaided

An eligible operator can bring up the gateway and complete a synthetic chat without assistance.

- **Status:** Active
- **Characteristic:** Interaction Capability
- **Sub-characteristic:** Learnability
- **Business importance:** High
- **Technical risk:** Medium

The predeclared pass bar is **at least 2/3 of at least 3 valid participants completing the main task unaided**.
The risk is medium because the gateway flow is implemented and staged, but unfamiliar operators may still fail to discover
the documented configuration and plugin workflow without facilitator help.

## Scenario

### Source

An eligible operator who has not been coached through this gateway's setup.

### Stimulus

The operator receives a clean supplied workspace, reviewed image, test port and private Compose settings location and is
asked to try the gateway with a harmless synthetic message.

### Environment

In-person, on the university network, against staging, with the synthetic seed reset before the session and no real
provider key, user content or payment.

### Artifact

The setup documentation, packaged gateway and instrumented staging Compose service.

### Response

The operator brings the gateway up, confirms health and obtains the documented synthetic response with its plugin trace.

### Response Measure

The main-task unaided completion rate among valid participants.

## QRT-01

**Status:** Not verified
**Level:** manual
**Runs at:** [UT-01](../../usability-tests/ut-01/README.md)
**Why Manual:** Whether a person can learn and complete the main task without help cannot be established by automated tests
or content-free telemetry; the observer must record completion and assistance.

### Procedure

1. Run at least three valid, eligible participant sessions using the fixed UT-01 protocol and reset seed.
2. Exclude sessions lacking consent, recording, profile match, complete data or a usable technical run.
3. Count the main task as `Unaided`, `Assisted` or `Failed` using the criteria fixed in UT-01. Reconcile observer notes with
   the private session export and retain only sanitized evidence publicly.

**Pass when:** at least 2/3 of at least 3 valid participants complete the main task unaided. This is the same bar stated
in the UT-01 protocol and analysis plan.
