# QR-04: Install And Start From The Setup Guide Alone

A developer new to the project installs and starts the gateway using only the setup guide.

- **Status:** Active
- **Characteristic:** Flexibility
- **Sub-characteristic:** Installability
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

A developer or DevOps operator who has not worked on the project before.

### Stimulus

The developer follows `docs/setup.md` from a fresh clone to the first request through two plugins.

### Environment

A clean machine with Python 3.12 and Git, no previously created virtual environment and no provider key.

### Artifact

The setup guide, the project's dependency declarations and the default plugin configuration.

### Response

The gateway starts with the two default plugins and answers the documented test request with the fake provider's reply.

### Response Measure

The developer reaches the documented `fake: HELLO` response within 15 minutes, running only commands that appear in `docs/setup.md`, with 0 interventions from a team member.
